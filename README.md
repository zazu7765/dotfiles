# dotfiles  
Personal dotfiles, updated as I find/make configs I want to transfer over computers or share with friends
## specifics:  
- Current WM: nothing (mac)
- Current TERM: Ghostty (mac/linux)
- Current EDITOR: nvim, emacs, hx 
- Current SH: fish

## installation guide:
- `$ stow -t ~/.config config/{folder}` where {folder} is replaced by the config you want to symlink
- On Fish, script is stowdots config <folder>
